# שערי השמש — חנוך עב

אפליקציית אנדרואיד שעובדת דרך המצלמה. מרימים את הטלפון לכיוון השמש ורואים מעל התמונה את ששת שערי השמש.

## מה מוצג
- **האופק:** קו לבן.
- **מזרח (זריחה) ומערב (שקיעה):** מסגרת זהב עם שנתות.
  - כל שנתה היא אזימוט הזריחה (או השקיעה) מהמקום שלך, ביום שבו מתחיל חודש מקראי.
  - מעל כל רצועה: מספר השער ומספר הימים.
  - מתחת לכל שנתה: התאריך הלועזי.
- **קו כתום "היום":** הזריחה והשקיעה של היום. השער הנוכחי מודגש.
- **שנתות אפורות קטנות:** המעבר בכיוון ההפוך (צפונה או דרומה).
- **טבעת צהובה:** המיקום המחושב של השמש עכשיו.

## כיול
המצפן של הטלפון יכול לטעות בכמה מעלות.
- כשהשמש נראית: מכוונים אותה לכוונת ולוחצים **"כייל לפי השמש"**.
- הכיול נשמר. **"איפוס כיול"** מבטל אותו.

## בנייה והתקנה
1. מאגר GitHub חדש (למשל `sun-gates`) ובו כל הקבצים.
2. את `.github/workflows/build.yml` יוצרים ידנית: **Add file ← Create new file**.
3. **Actions** בונה לבד. ה-APK מופיע תחת **Releases** בשם `SunGates-N.apk`.

מזהה האפליקציה הוא `org.luach364.gates`. היא נפרדת לגמרי מ"לוח 364" ומותקנת לצידה.
